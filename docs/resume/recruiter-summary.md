# Recruiter Summary

This project is a simulated market-data trading platform built to demonstrate platform engineering and reliability engineering skills in a trading-style environment.

It includes:
- distributed services
- event streaming
- API exposure
- observability
- infrastructure automation
- operational runbooks
- incident response documentation

The project is intended to show how I approach system behavior, troubleshooting, monitoring, and service recovery, not just how I deploy containers.
