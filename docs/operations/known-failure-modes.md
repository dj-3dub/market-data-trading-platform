# Known Failure Modes

## Broker Unavailable
Impact: event flow interrupted

## Consumer Stall
Impact: stale processing despite healthy upstream services

## Gateway Degradation
Impact: slow or failed consumer access to system state

## Metrics Blind Spot
Impact: degraded detection and longer recovery time

## Docker Network Communication Issue
Impact: services healthy in isolation but unable to interact

## Stale Data Condition
Impact: technically "up" but functionally degraded
